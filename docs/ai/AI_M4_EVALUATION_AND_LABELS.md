# AI-M4 图像候选、混合渲染与标识门禁

## 当前交付

本阶段完成的是默认关闭的本地框架：

- 结构化 Caption + 五个声音数值 + Mood → 确定性提示词；
- Z-Image-Turbo 与混元极速候选共用的注入式 transport 契约；
- 864×1152、8 步、单图、`promptExtend=false` 的固定请求；
- 1080×1440 基础图 + 本地声纹叠层 + 品牌文字的 Canvas 合成；
- 结果页和分享图可见“AI 生成”标签；
- 隐式标识未被真实服务验证时禁止保存或分享；
- 24 组输入 × 3 Mood × 2 匿名候选的盲测计划。

它不包含真实供应商调用、真实图片、压缩质量样本、元数据写入服务或正式供应商结论。

## 确定性提示词

模板固定使用：

- 经过 AI-M3 再次过滤的 environment、sources、dynamics、materials、spatial；
- loudness、low/mid/high energy、changeRate 的百分制量化值；
- 三种 Mood 的固定艺术解释；
- 由 job ID 与五个结构值稳定选择的八种构图方向；
- Sound Palette 的雾化叠色、柔和边缘、细颗粒和克制留白；
- 固定 negative prompt，排除文字、水印、界面、写实人物、人脸、二维码和杂乱拼贴。

相同输入得到同一 prompt hash 与 seed；不使用 `Date.now()`，不调用第二个语言模型，不保存
完整提示词到任务或分享清单。Caption 中的提示注入、电话、邮箱、地址和逐字内容会在模板
前再次过滤。

## 图像候选契约

两家候选都必须满足：

- 864×1152；
- 单次一张；
- 8 步；
- prompt 扩写关闭；
- 展示格式只能是 mock / WebP / JPEG；
- 尺寸或格式错误直接降级；
- 只有明确标为瞬断的错误允许一次重试；
- provider request ID 只保留安全字符；
- 候选适配器默认关闭，国内地域和正式能力未经证据不得打开。

当前模型名称带有 `candidate (unverified)`，不能作为官方能力或可用地域证明。

## 混合渲染与分享

`ai-hybrid-renderer.ts` 负责：

1. 把 3:4 AI 基础图铺满 1080×1440；
2. 以 screen 混合模式叠加确定性的本地声纹线条与颗粒；
3. 在右上角绘制可见“AI 生成”；
4. 绘制品牌、日期与最多三个过滤后的声音线索；
5. 导出完成后由调用方把高分辨率 Canvas 释放为 1×1。

客户端 Canvas 只能证明显式标识存在，不能证明 PNG/WebP 元数据仍保留。分享清单因此固定为
`finalizeRequired=true` 与 `pending-server-finalize`。只有受信服务返回：

- 1080×1440；
- 显式标识检测通过；
- 隐式元数据检测通过；
- verification = `real-passed`

时才能交给相册或分享接口。仓库的 mock evidence 永远是 `mock-only`，会被门禁拒绝。

## 盲测计划

- 八类：安静、雨、街道、环境人声、自然、音乐、突发声、持续低频；
- 每类三个固定合成或公开许可输入方向，共 24 组；
- 每组 good / neutral / low 三种 Mood；
- 每个 Mood 同时准备匿名 A/B 两个候选，共 144 个评分项；
- 评价吸引力、声音关联感、构图变化、风格稳定性、延迟、成本和可分享性；
- 评测表只显示 A/B，不出现供应商名称；
- 密封映射单独保存；
- 即使 144 项全部评分，程序也只返回 `ready-for-human-decision`，不会自动宣布赢家。

当前只有计划与固定 mock 评分测试，没有真实图片盲评；Z-Image 或混元均未被选为正式供应商。

## 真实门禁

AI-M4 真实通过仍需要：

1. 两家正式账号、国内地域和条款确认；
2. 同一 24 组输入生成真实 144 对候选图；
3. 真实延迟、失败率、单张成本和 150–350KB 压缩质量；
4. 至少一台 Android 与一台 iPhone 全屏画质和分享检查；
5. 服务端 finalize 的显式/隐式标识独立验证；
6. 完整盲评后由人工作出供应商决定并记录理由。
