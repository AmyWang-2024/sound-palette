# AI 服务运维、灰度与回滚手册

## 上线前

- 密钥只进入服务端密钥管理系统；Git、日志、小程序包和截图中不得出现值；
- 密钥登记只保存 provider、key ID、active/standby/retired 和时间；
- 至少准备一个 standby key，轮换时先验证、再激活、最后退休旧 key；
- 配置单用户限速、每日/月度额度、项目日预算、并发和超时；
- 配置 Caption/Image 各最多一次瞬断重试；
- 配置删除巡检，成功、失败、取消、超时和 TTL 五类均必须有证据；
- 配置结果 TTL、日志脱敏与 30 天清理；
- kill switch 开启、灰度 0%、真实 provider 关闭。

## 运行保护

- 预算利用率达到 80% 告警，达到 100% 停止新预占；
- 并发达到上限时立即本地降级，不排无限队列；
- 连续供应商失败达到阈值后熔断；
- 冷却期后只允许一个 half-open 探针；
- 探针成功关闭熔断，失败重新打开；
- P95、成功率、删除失败、标识失败、成本和供应商限流进入告警；
- 日志只包含 job ID、阶段、固定错误、请求 ID、耗时、成本和删除状态。

## 小范围灰度

只有发布门禁状态为 `published` 后才允许灰度：

1. 保持 0%，核对线上服务与平台版本；
2. 关闭 kill switch；
3. 从人工批准的小比例开始；
4. 每阶段检查成功率、P50/P95、成本、删除和标识；
5. 不通过则不扩大；
6. 用户分桶由 user ID + rollout version 的稳定哈希决定。

## 一键回滚

1. `enabled=false`；
2. `killSwitch=true`；
3. `percentage=0`；
4. 停止新的任务和上传授权；
5. 已收到音频的任务优先完成 Caption 后删除；无法安全完成则删除并释放额度；
6. 已得到可恢复图片的任务保留结果并完成结算；
7. 其他预占全部释放；
8. 小程序回退本地声纹画；
9. 记录时间、原因、受影响 job 数、删除与额度核对；
10. 未复盘和重新通过门禁前不恢复。

## 巡检

每日检查预算、熔断、供应商错误、删除失败、过期对象、额度不平、标识失败和密钥年龄。
每次发布检查体验版、隐私版本、条款版本、服务版本、模型版本和 rollback version 一致。
