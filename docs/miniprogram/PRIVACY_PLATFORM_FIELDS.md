# 用户隐私保护指引平台字段草案

以下文本供管理员录入微信公众平台时参考。平台字段名称和可选项以提交当天后台为准；
管理员必须逐项核对，不能机械复制。

## 麦克风

- 使用场景：用户主动点击“开始十秒聆听”，同意隐私说明并允许麦克风后；
- 使用目的：在设备本地计算环境声音的相对响度、低频、中频、高频和变化率，生成抽象图片；
- 处理方式：接收十秒实时 PCM 数值帧，不识别或转写语音，不推断说话人身份；
- 存储与传输：不上传声音、PCM 帧或分析摘要；微信可能生成的本地临时录音文件在停止后
  主动删除，删除失败或状态不确定时丢弃结果。

## 相册写入

- 使用场景：用户在结果页主动点击“保存图片”；
- 使用目的：把本地 Canvas 生成的 1080×1440 PNG 写入系统相册；
- 处理方式：只写入最终图片，不包含原始声音、PCM、临时路径或麦克风诊断；
- 拒绝后：不写入相册，用户仍可查看作品或稍后重新授权。

## 当前版本未使用

- 不收集手机号、邮箱、昵称、头像、位置、通讯录或设备广告标识；
- 不使用微信登录、业务账户、服务器、数据库、对象存储或项目统计接口；
- 不上传声音、五个声音数值、Mood、seed、标签或作品；
- 不提供语音转文字、声音身份识别或作品社区。

未来 AI 版的临时声音上传、账户和额度不属于 W5 本地版。只有完成独立 AI 里程碑并同步
更新实现、隐私指引、服务协议和审核材料后，才允许在平台增加相应用途。
