# 我的声音相册：用户隐私保护指引草案

本草案对应 W2 实际实现，用于微信公众平台“用户隐私保护指引”的配置准备。平台最终字段
和措辞必须由管理员在提审前逐项核对。本草案不代表已经备案、通过审核或发布。

## 产品与主体

- 产品中文名称：我的声音相册；
- 英文品牌：Sound Palette；
- 主体：中国大陆个人主体；
- 服务类目：工具 > 图片处理；
- 当前版本不使用服务器或数据库。

## 麦克风使用

- 触发方式：只有用户主动点击“开始十秒聆听”，同意隐私保护指引并授权
  `scope.record` 后才启动；
- 使用目的：将十秒环境声音的相对响度、低频、中频、高频和变化率转换为抽象画面；
- 处理方式：在设备本地接收微信 `RecorderManager` 返回的 16 kHz、单声道、PCM
  实时帧，以 2048 点窗口计算频谱数值；
- 明确排除：不识别或转写语音，不推断说话内容或说话人身份，不上传原始音频、PCM
  帧或声音摘要。

## 临时录音文件与留存

- 微信录音接口可能在本地产生临时录音文件；
- 每次正常结束、用户提前停止、切后台、中断或异常时，程序都会停止录音；
- 收到 `onStop` 返回的临时路径后，在下一事件循环立即调用 `FileSystemManager.unlink`
  删除；若微信仍短暂占用文件，则在约 1.5 秒内有界重试并再次确认文件已不存在；
- 删除失败或文件状态无法确认时丢弃本次作品结果并向用户明确提示，作为发布阻塞问题处理；
- 实时分析窗口、帧数组和声音摘要只存在于当前小程序内存，不写入持久化存储；
- 当前版本不调用音频上传、保存文件、缓存音频或数据库 API。

## 权限拒绝与撤回

- 用户可以拒绝隐私保护指引或麦克风权限，程序不会启动麦克风，并提供不使用麦克风的
  内置示例；
- 用户可以在微信的小程序设置中关闭麦克风权限；
- 切到后台或离开页面会立即停止本次聆听，返回后需要用户重新主动开始。

## 相册写入与分享图片

- 只有用户在结果页主动点击“保存图片”时，程序才调用相册写入能力；
- 保存内容是本地 Canvas 生成的 1080×1440 PNG，不包含原始声音、PCM 帧、文件路径或
  麦克风诊断信息；
- 用户拒绝相册权限时不会写入相册，仍可查看作品并重新选择；
- 点击“分享图片”时优先调用微信图片分享菜单；不可用或失败时只在本机预览图片；
- 导出使用的高分辨率 Canvas 在操作后立即释放，临时 PNG 在保存、分享或预览操作结束后
  主动删除；临时图片不上传到项目服务器。

## 后续变更门禁

W3 已在本草案加入“相册写入”与本地分享图片用途；公众平台最终指引仍必须由管理员在
W5 提审前逐项配置并核对。AppID、AppSecret 和管理员凭证不得写入公开代码或本指引。
