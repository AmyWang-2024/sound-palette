## 微信开发者工具

1. 导入仓库根目录，确认读取本机 `project.private.config.json` 中的 AppID。
2. 执行“编译”，确认首页显示“我的声音相册”和动态抽象画面，控制台无错误。
3. 点击“播放十秒示例”，确认倒计时从 10 到 0，进度条连续前进，画面随示例变化。
4. 进入 Mood 状态，依次选择“好 / 不好不坏 / 不好”：
   - 色彩、亮度、纹理密度和运动倾向明显不同；
   - 基底形态、色带和粒子的基础位置不跳变。
5. 点击“收下这张声音相片”，确认结果页显示三个标签和基底/流动/闪烁比例。
6. 点击“再听一个示例”，确认返回首页且能重复完成流程。
7. 切到后台至少 5 秒再返回，确认动画暂停后恢复，没有重复计时器或控制台错误。
8. 在 320、375、430 CSS 像素宽度模拟器中检查按钮、Mood 选项和比例文字无裁切。

## 微信真机预览

最终发布前必须分别在至少一台 iPhone 和一台 Android 微信上扫码预览：

1. 完整执行上述步骤 2–7。
2. 观察十秒动画是否流畅、手机是否明显发热、页面是否闪退。
3. 确认本里程碑未弹出麦克风、相册或隐私授权。
4. 记录机型、系统版本、微信版本、结果和异常截图。

在这些步骤由真实设备执行并记录前，不得声称 W1 真机验证通过。
