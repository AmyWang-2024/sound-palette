# W4 真机与审核 QA 清单

本清单用于最终集中验收。自动化、模拟器和开发者工具不能替代 Android 与 iPhone 真机。

## 已完成的本机证据

- 2026-07-27：15 个测试文件、53 项测试通过；
- 2026-07-27：Web 生产构建、小程序共享核心构建和小程序 TypeScript 检查通过；
- 2026-07-27：微信开发者工具使用真实本机 AppID 预览编译成功；
- W4 预览包：119,579 Byte，低于 1.5MB 门禁；
- W4 预览二维码仅作为临时真机入口，不代表体验版、审核或发布。

## 开发者工具

- [x] 使用本机私有 AppID 编译，无项目编译错误；
- [x] 预览包低于 1.5MB，记录主包字节数；
- [ ] 320、375、430 CSS 像素宽度下无按钮、标签或文字裁切；
- [ ] 导出卡片为 1080×1440，中文与页脚完整；
- [ ] 网络面板中本地完整流程的项目请求数为 0；
- [ ] 首页加载时不请求麦克风、相册或隐私权限。

## Android 与 iPhone 共用流程

- [ ] 首次隐私同意、拒绝和再次进入均符合 `W2_MANUAL_TEST.md`；
- [ ] 麦克风允许、拒绝、从设置恢复均正常；
- [ ] 十秒完成、提前停止、切后台、中断和连续三次聆听均释放麦克风；
- [ ] 临时录音文件明确显示已删除或已不存在；
- [ ] 安静、说话、低频、中频和拍手产生明显数据与视觉差异；
- [ ] 三种 Mood 改变艺术解释但不重置主体构图；
- [ ] 保存、相册拒绝与恢复、图片分享、取消和预览兜底均正常；
- [ ] 分享图像素、标签、比例、Mood、时间和品牌文字完整；
- [ ] 页面保持竖屏，旋转设备后布局不溢出、不丢失当前状态；
- [ ] 强制关闭并重进后没有残留录音、导出或权限加载状态。

## 性能与稳定性

- [ ] 中低端 Android 连续完成十次聆听和导出，不崩溃、不卡死；
- [ ] 低端档限制为 DPR 1.5、20 FPS、48 粒子；
- [ ] 未知能力默认中档：DPR 2、24 FPS、72 粒子；
- [ ] 高档仍不超过 DPR 2、30 FPS、96 粒子；
- [ ] 切后台期间动画停止，返回后只恢复一个动画循环；
- [ ] 导出完成后高分辨率 Canvas 释放，临时 PNG 删除；
- [ ] 十次流程后手机没有异常持续发热或系统麦克风指示残留。

## 阻塞判定

以下任一项出现即阻止提审和发布：PCM 无法解析、临时录音或图片清理无法确认、持续占用
麦克风、本地流程产生项目网络请求、权限文案与行为不一致、导出裁切、低端机崩溃、
Android 或 iPhone 任一平台缺少最终记录。
