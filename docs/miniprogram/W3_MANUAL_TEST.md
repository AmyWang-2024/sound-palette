# W3 导出与分享人工测试

W3 自动测试与构建不能证明微信相册、图片分享菜单或真机中文字没有裁切。最终验收必须
分别记录 Android 和 iPhone 的机型、系统版本与微信版本。

## 1080×1440 PNG

1. 完成一次内置示例和一次真实麦克风流程，分别选择三种 Mood 导出。
2. 点击“保存图片”，首次只在此动作后出现相册权限请求。
3. 在系统相册检查图片像素为 1080×1440。
4. 检查作品、生成时间、Mood、基底/流动/闪烁比例和三个标签全部存在。
5. 检查中文、百分比、标签和页脚没有裁切、重叠或超出画面。

## 权限与失败

1. 清除相册权限后点击保存并拒绝，确认没有写入图片，页面仍可继续使用。
2. 从微信设置重新允许相册权限，再次点击保存，确认无需重启即可成功。
3. 连续保存三次，确认每次只新增一张图片，页面不冻结。
4. 模拟 PNG 生成失败时，确认显示可理解提示，不把失败写成已保存。

## 分享

1. 点击“分享图片”，确认优先出现微信图片分享菜单。
2. 取消分享，确认页面显示“已取消分享”，不显示错误。
3. 在不支持图片分享菜单的环境中，确认退回图片预览并说明可长按保存或分享。
4. 分享或预览后再次导出，确认高分辨率画布已经释放且没有使用上一次作品。

## 隐私与清理

1. 导出期间检查网络面板，确认没有 `request`、`uploadFile` 或 `downloadFile`。
2. 保存和分享图片不接触麦克风临时文件。
3. 操作结束后若页面提示“临时图片清理状态无法确认”，记录日志并阻止发布。

在 Android 和 iPhone 均完成以上步骤前，不得声称 W3 真机验收通过。
