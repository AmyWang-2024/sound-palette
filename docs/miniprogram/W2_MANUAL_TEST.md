# W2 麦克风与隐私人工测试

W2 必须在 Android 微信和 iPhone 微信真机验证。开发者工具不支持可靠验证真实采样率、
PCM 端序、系统麦克风占用或临时文件清理。

## 当前状态

- Android：旧构建曾完成基础流程，但清理与视觉响应已更新，最新构建待重新完整验证；
- iPhone：暂无可用设备，构成 W2 提交和后续发布门禁；
- 自动测试、Web 构建和小程序构建已通过，不等同于真机通过；
- 在两端完成前不得声称 W2 真机验收通过。

## 首次隐私与权限

1. 清除该小程序的隐私与麦克风授权状态。
2. 点击“开始十秒聆听”，确认先出现产品隐私说明，且开始前没有占用麦克风。
3. 点击“暂不使用麦克风”，确认不弹录音授权、不出现系统麦克风指示，并可进入示例。
4. 再次开始，点击“同意并继续”，随后拒绝 `scope.record`：
   - 页面提示权限未开启；
   - 可进入微信设置；
   - 拒绝后仍可使用示例模式。
5. 在设置中开启麦克风权限，确认无需重启即可开始十秒聆听。

## PCM 与声音摘要

依次测试安静环境、正常说话、持续低频声、约 1 kHz 中频声和拍手：

1. 倒计时约十秒，画面实时变化，过程中不闪退或明显卡顿。
   “声音响应”百分比应随说话、安静和拍手明显变化；基础构图位置保持稳定，但形态大小、
   色带振幅、粒子数量和扰动速度应有可见差异。
2. 结果的“本次本机分析”应显示：
   - `16000 Hz · 单声道`；
   - 首帧字节数大于 0，通常为 4096；
   - 分析窗口大于 0；
   - 临时文件为“已立即删除”或“文件已不存在”，并显示实际删除尝试次数。
   - “状态无法确认”和“删除失败”都属于失败，不得当作已清理。
3. 持续低频声应提高“基底”，中频声应提高“流动”，拍手/明亮瞬态应提高
   “闪烁”或变化率表现。
4. 观察日志和网络面板，确认没有 `uploadFile`、`request` 或音频持久化调用。

必须记录机型、系统版本、微信版本、首帧字节数、分析窗口数和清理状态，用于确认
Android/iOS 的 PCM 格式与小端序解析一致。

## 停止、异常与重复聆听

1. 开始后 1 秒内点击“停止聆听”，确认回到首页并显示已清理。
2. 开始后立刻切后台，确认系统麦克风指示消失；返回后需要重新开始。
3. 录音时发起或接听通话/语音中断，确认结果被丢弃、麦克风释放、临时文件清理。
4. 连续完整聆听三次，确认没有重复回调、倒计时加速或持续占用麦克风。
5. 强制关闭小程序后再次进入，确认没有残留录音状态。
6. 若页面显示“删除失败”，停止 W2 验收并保留设备日志，不得继续发布。
   “状态无法确认”按同样规则处理。同时记录“清理诊断”一行；该内容只包含脱敏错误类型，
   不包含临时文件路径。
